# Student Attendance System

Aplikasi absensi mahasiswa sederhana berbasis HTML, CSS, dan JavaScript.

## Fitur
- Menambahkan nama, NIM, tanggal, dan status kehadiran.
- Melihat daftar absensi.
- Mencari data berdasarkan nama atau NIM.
- Memfilter data berdasarkan status kehadiran.
- Menghapus satu catatan atau seluruh data.
- Mengekspor data ke CSV.
- Menyimpan data di browser menggunakan `localStorage`.

## Cara menjalankan
1. Download atau clone repository ini.
2. Buka `index.html` di browser.
3. Tambahkan catatan absensi melalui formulir.

Tidak memerlukan instalasi atau server khusus.

## Catatan
Data disimpan secara lokal pada browser/perangkat yang digunakan. Data tidak tersinkronisasi antarperangkat dan dapat hilang jika data situs/browser dihapus. Untuk penggunaan multi-user atau penyimpanan terpusat, aplikasi perlu dikembangkan dengan backend dan database.

## Teknologi
- HTML5
- CSS3
- Vanilla JavaScript
